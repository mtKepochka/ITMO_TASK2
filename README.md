# Ticket Automation PoC

Компактный локальный прототип классификации и безопасной маршрутизации
тикетов поддержки для трека «ИИ».

## Быстрый старт

Требуется Python 3.11+.

```bash
python -m pip install -e '.[dev]'
make test
```

Команды demo и описание архитектуры будут добавлены вместе с работающим
end-to-end сценарием.
